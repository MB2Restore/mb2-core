================================================================================
IF YOU ENCOUNTER ISSUES
================================================================================

Issue: "Cannot find module sqlite3"
Fix: In backend folder, run: npm install

Issue: "Port 5000 already in use"
Fix: Kill the process using port 5000 or restart your machine

Issue: "Failed to fetch from http://localhost:5000"
Fix: Make sure backend server is running (Terminal 1 should show "Server running")

Issue: Need to reset database
Fix: Delete jobs.db file, then restart backend (it will recreate it)
